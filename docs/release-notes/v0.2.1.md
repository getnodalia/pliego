Pliego en español deja de mostrar textos en inglés: los títulos y rótulos que seguían sin traducir en el panel Propiedades, la paleta de comandos y los diálogos.
*Pliego in Spanish no longer shows English text: the labels and titles that were left untranslated in the Properties panel, the command palette and the dialogs.*

## Español

### Correcciones
- **Panel Propiedades:** los rótulos de posición y tamaño (X, Y, An, Al) de objeto, puntos de ancla, guías y documento salen en el idioma de la interfaz.
- **Paleta de comandos:** los nombres de los comandos se muestran traducidos; los nombres de tus estilos se respetan tal como están.
- **Diálogos:** el botón Aceptar de los diálogos genéricos ya no aparece como OK.
- **Una prueba lo vigila:** una nueva prueba abre cada comando del menú con la interfaz en español y falla si queda un texto en inglés que el catálogo ya traduce.

## English

### Fixes
- **Properties panel:** the position and size labels (X, Y, W, H) for objects, anchor points, guides and the document now follow the interface language.
- **Command palette:** command names are shown translated; the names of your own styles are left as they are.
- **Dialogs:** the OK button of generic dialogs no longer reads OK in Spanish.
- **A test guards it:** a new test opens every menu command with the interface in Spanish and fails if an English text that the catalog already translates is still drawn.
